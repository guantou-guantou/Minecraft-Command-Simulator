# 游戏内验证清单

下面这些行为是按基岩版通行做法或参考文档写的,没有在网易版里逐项核对。有机会在游戏里测一下,把结果告诉我,我据此改模拟器。每一项写明了怎么测、要记录什么。

## 0.3.0 新增的指令

已经核对并按结果改过的:`/damage`(半颗心、护甲和抗性生效、创造模式失败、成功和失败的提示)、生物最大生命值(取自 Wiki)、瞬间治疗和瞬间伤害(取自 Wiki)、`/querytarget` 的输出格式、`/spreadplayers` 的正方形区域、`/me`、`/toggledownfall`、`/alwaysday`、命令方块的聊天输出格式、`/function` 找不到函数时的提示。网易版不加模组时不能添加函数,所以 `/function`、`/schedule`、函数限制没法测。
