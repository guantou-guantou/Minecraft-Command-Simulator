## 0.3.3(已完成)

函数导出和警告、`mcsim test --jobs`、指令语法检查提速并放进后台线程。见 CHANGELOG。

没有做的:界面里的测试面板并行、大结构导入导出放后台线程。两者都还没有测过是否真的卡(大结构要用你给的样本量),量过再定。

## 0.4.0(计划)

- **AI 接入(OpenAI 格式的 API key)**:设置里填 base URL、模型名和 key,key 用 `safeStorage` 加密、只在主进程里用;默认关闭。像 IDE 那样:框选脚本引用给 AI 提问;让 AI 按要求生成代码,代码块有"复制""插入""替换选中内容",先显示差异预览再应用,并自动给出 `parse`、`lint` 结果。发送前显示将发送的内容;"带上整份脚本"**默认勾选**;AI 的回复语言跟界面语言走(脚本本身始终是英文)。附一份 `docs/AI提示词.md`,命令清单在构建时从语法表生成,界面有"复制给 AI"按钮。面板按"后端可换"写。
- **ACP**:在 API 之后接入 Agent Client Protocol(启动用户自己装的 agent 子进程)。agent 读写文件的请求只给当前脚本,写入先转成差异预览,执行终端命令默认拒绝。
