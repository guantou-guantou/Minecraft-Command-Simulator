# 路线图

## 0.3.1(已完成)

终端历史、/give @s air、终端输出语言、禁止嵌套 chain、断链写法(if:/un:、pass、fter=/eside=)、un 后面可以带 /。见 CHANGELOG。

## 0.3.2(计划)

1. **EX 版 FMBE**:官方 EX 前置(3D 方块、2D 方块、物品三个类别,每类 5 条)已验证能在引擎里跑通。要做的是面板里的前置版本选择、EX 变量、粘贴自定义前置的入口。
2. **FMBE 预览按游戏自己的变量算**:现在预览读的是自定义输入变量(`v.xpos`、`v.scale` 等),变量改名就认不出。FMBE 的本质是用自定义变量算出游戏里原有动画读的变量(`v.head_position_x`、`v.body_x_rot` 等),所以预览应该只读这些输出变量,不依赖输入变量的名字,标准版和 EX 版一起解决。先做一次验证:用引擎跑真实的 Molang 得到输出,和现有预览的矩阵对比,能对上才换;对不上就保留现有预览并补上 EX 的拉伸。
3. **断链改成单链加 setblock 切换模式**:断口处放一个默认模式的脉冲命令方块(它自己也写指令,不空着),条件成立时 `setblock` 成连锁模式,主链运行一次,最后 `setblock` 回脉冲模式。整条断链是一条链、一个勾选项,不再生成模板链和主链。需要引擎里 `setblock` 在命令方块之间切换时保留指令。
4. **终端输出的中文文案补全**:需要游戏里的原文。
## 更远的计划
