# 路线图

## 0.3.1(计划,已记录,尚未开始)

1. **终端历史**:在终端输入框按上键(下键往回),可以填入以前发送过的内容。
2. **`/give @s air`**:现在模拟器报错,游戏里可以执行。游戏里的行为:
   - `sendcommandfeedback` 开启时显示"已将 1 个空气给予 xxx"(开启才有);
   - 一直显示"你被给予 1 个空气";
   - 玩家背包不会有任何变化。
3. **终端输出语言**:终端里游戏输出的文字(指令反馈、错误提示等)要和界面选择的语言一致,和游戏的规则一样。现在界面语言只影响界面文字,游戏输出一直是英文。需要一份中文文案表,中文文案以网易版游戏里的原文为准。

4. **禁止嵌套的 `chain`**:游戏里命令方块链是一排物理方块,不能嵌套。现在缩进写在另一条链里面的 `chain` 头不会报错,而是被当成一条新链,它后面缩进的指令也会被归到这条新链里,和写的人想的不一样。改成报错:"`chain` 头不能缩进,命令链不能嵌套"。
5. **"断链"写法的支持**(见技能文档里的"断链优先于降频"):现在已经能用现有语法写出来(检测链加主链,中间留一格空气,命中时 `clone` 模板连锁块补上,主链最后 `setblock` 复原成空气,已用脚本验证),但要手算坐标。计划加:
   - `chain 主链(after=检测链, gap=1)`:位置和朝向按检测链的末端自动算出来,中间留 `gap` 格;
   - 检查:检测链末端朝向的格子既不是方块也不是主链入口时给出提示,`gap` 对不上时报错,避免断口位置写错;
   - 教学文档加一节"断链"的完整示例。
## 更远的计划

- 补全 `ride`、`event`、`loot`、`locate`、`place` 等还没有实现的指令。
- 把核心(`src/language`、`src/engine`、`src/nbt`、`src/bdx`、`src/convert`)拆成独立的包,做 VS Code 插件(语言服务、诊断、补全、悬停、运行测试)。
- AI 写脚本:提示词文档加"复制给 AI"按钮,再接入 API(密钥加密保存,默认关闭,先预览差异再应用,用解析器和测试自动检查 AI 的结果)。
- Java 版方言:同一份语法表和引擎按方言分支(选择器、`execute` 子命令、`/data`、坐标规则)。
- Windows 7 旧版安装包:只有需求足够才做(需要 Electron 22,没有安全更新)。
